# New in Streamybox 1.6.2

- Profiles: switching to a second profile no longer fails when YouTube (SmartTube) or other apps keep separate data. Error messages explain in plain words what happened.
- Streamarr per profile: its own sign-in, server and settings in each profile (Settings › Profiles › App data per profile).
- Favourites per profile: every profile has its own favourites on the home screen, edited in Settings › Appearance › Favourites, entirely with the remote.
- Faster and smoother: the home screen opens and comes back faster, menus scroll more evenly, and much less runs in the background. Apps from the Store (e.g. Streamarr 0.20.1) are fully optimised right after an update.
- Streamarr 0.20.1 comes preinstalled or as an update.
- This update arrives as a system update through Settings › System › Software update. The box restarts into recovery once; apps, profiles and settings are kept.
- If the screen stays black for more than 10 minutes after the restart for the system update, unplug the power for 10 seconds and plug it back in – the installation then continues.

# Streamybox 1.2.2 (10020)

## Deutsch

# Neu in Streamybox 1.2.2

- Die Oberfläche lässt sich getrennt von der Bildschirmauflösung einstellen: Einstellungen › Bild › Auflösung der Oberfläche. Zum Beispiel Menüs in Full HD für flüssigere Bedienung, Videos weiterhin in voller 4K-Auflösung.
- Die UI-Skalierung bezieht sich jetzt auf die gewählte Oberflächen-Auflösung; das Layout bleibt auf jeder Stufe gleich.
- Wird eine kleinere Bildschirmauflösung bestätigt, passt sich eine größere Oberfläche automatisch an.
- Mit dem neuen Systemabbild laufen Apps im Vordergrund wieder auf den schnellen Prozessorkernen. Das gilt für alle Apps, auch Streaming-Apps, Jellyfin und SmartTube.
- Mit dem neuen Systemabbild weckt der Fernseher die Box über HDMI-CEC: Fernseher einschalten oder auf den Eingang der Box wechseln genügt.

## English

# New in Streamybox 1.2.2

- The interface resolution can be set separately from the screen resolution: Settings › Picture › Interface resolution. For example, menus in Full HD for smoother navigation while videos keep full 4K resolution.
- UI scale now refers to the chosen interface resolution; the layout stays the same at every size.
- When a smaller screen resolution is kept, a larger interface adjusts automatically.
- With the new system image, foreground apps run on the fast CPU cores again. This applies to every app, including streaming apps, Jellyfin and SmartTube.
- With the new system image, the TV wakes the box over HDMI-CEC: turning the TV on or switching to the box's input is enough.

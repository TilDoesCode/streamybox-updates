# Streamybox 1.2.3 (10021)

## Deutsch

# Neu in Streamybox 1.2.3

- Softwareupdate kann künftig auch Streamybox OS selbst aktualisieren: Paket laden, Signatur prüfen, neu starten und installieren. Apps und persönliche Daten bleiben erhalten.
- Dafür braucht die Box einmalig eine eigene Wiederherstellungsumgebung, die per USB eingerichtet wird. Bis dahin zeigt Softwareupdate die installierte Systemversion und den Hinweis zur Einrichtung.
- Schlägt eine Systeminstallation fehl, bevor etwas geschrieben wurde, startet Streamybox mit dem bisherigen System neu und Softwareupdate erklärt, was passiert ist.
- Die Auflösung der Oberfläche funktioniert mit allen Systemversionen.

## English

# New in Streamybox 1.2.3

- Software Update can now also update Streamybox OS itself: download the package, check its signature, restart and install. Apps and personal data are kept.
- This needs a one-time recovery setup on the box over USB. Until then Software Update shows the installed system version and a note about the setup.
- If a system installation fails before anything is written, Streamybox restarts with the previous system and Software Update explains what happened.
- The interface resolution works with every system version.

# New in Streamybox 1.2.3

- Software Update can now also update Streamybox OS itself: download the package, check its signature, restart and install. Apps and personal data are kept.
- This needs a one-time recovery setup on the box over USB. Until then Software Update shows the installed system version and a note about the setup.
- If a system installation fails before anything is written, Streamybox restarts with the previous system and Software Update explains what happened.
- The interface resolution works with every system version.

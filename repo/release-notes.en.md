# New in Streamybox 1.2.2

- The interface resolution can be set separately from the screen resolution: Settings › Picture › Interface resolution. For example, menus in Full HD for smoother navigation while videos keep full 4K resolution.
- UI scale now refers to the chosen interface resolution; the layout stays the same at every size.
- When a smaller screen resolution is kept, a larger interface adjusts automatically.
- With the new system image, foreground apps run on the fast CPU cores again. This applies to every app, including streaming apps, Jellyfin and SmartTube.
- With the new system image, the TV wakes the box over HDMI-CEC: turning the TV on or switching to the box's input is enough.
